# Researchscape prototype

ChatGPT export에서 논문 후보를 찾아 언급 빈도와 대화 맥락을 탐색하는 로컬 웹 앱입니다. Node.js 20 이상만 필요하며 패키지 설치나 API Key가 필요하지 않습니다. 선택적으로 공식 서지 API에서 제목·식별자를 조회할 수 있습니다.

```powershell
npm start
```

브라우저에서 **http://127.0.0.1:4317** 을 여세요. PowerShell 실행 정책으로 npm이 차단되면 `node server.mjs` 또는 `npm.cmd start`를 사용하세요. 첫 실행에서는 `data/`를 분석하므로 잠시 기다려야 합니다. 이후에는 파일이 바뀌지 않았다면 `.local/index.json`을 재사용합니다.

## 코드와 개인 데이터

Git에는 코드·테스트·문서·직접 작성한 공개 데모만 보관합니다. 실제 Export인 `data/`, 개인 판단과 캐시가 있는 `.local/`, 개인 경로 설정인 `researchscape.local.json`은 제외합니다. `.local/`에는 재생성할 수 없는 수동 검토·분류 기록도 있으므로 별도로 백업해야 합니다.

```powershell
npm run git:setup   # clone한 저장소에 커밋 전 데이터 검사 활성화
npm run git:check   # 현재 Git 인덱스의 추적 파일 확인
npm run start:demo  # 개인 대화 없이 공개 가상 예시로 실행: 포트 4319
```

실제 데이터는 현재 위치에 그대로 두어도 됩니다. 저장소 밖에 두고 싶다면 `researchscape.config.example.json`을 Git 제외 대상인 `researchscape.local.json`으로 복사해 경로를 지정하세요. 환경 변수는 로컬 JSON보다 우선하고, 설정이 없으면 기존 `data/`, `.local/` 경로를 사용합니다. 자세한 폴더 구조·백업·새 PC 복원 방법은 [코드와 데이터 분리](docs/code-and-data.md)에 있습니다.

## 사용 방법

- 그래프: 노드 크기는 선택한 언급 빈도 기준입니다. ‘최근 언급순’에서는 최신 논문부터 선택하되 크기는 전체 언급 수를 사용합니다. 상위 50/100/150개를 표시하며 검색하면 덜 자주 언급된 후보도 찾을 수 있습니다.
- 원문 링크 필터: 검색창 옆에서 **원문 링크 전체 / 원문 링크 없음 / 원문 링크 있음**을 선택할 수 있습니다. 본문·인용 메타데이터 또는 공식 서지정보에서 등록한 논문 링크 유무를 기준으로 목록·그래프·순위를 필터링합니다. arXiv·DOI·OpenReview 외에 ACL Anthology·CVF·PMLR·NeurIPS·IEEE·Nature 논문 경로도 인식합니다. 임의의 블로그나 일반 웹사이트는 논문으로 자동 승격하지 않습니다. 검색·후보 검토·날짜·대화 분류·프로젝트 선택과 함께 적용되며 `links` 값으로 보존됩니다. 상단 데이터 요약은 날짜·대화 분류·프로젝트 범위이고, 검색·링크·검토 결과 수는 그래프 하단에 표시됩니다. 링크 없음은 논문이 아니라는 의미가 아닙니다. Zotero Key와 ChatGPT 대화 주소는 이 필터의 대상이 아닙니다.
- 서지 정리: 상단 **서지 정리 → 공식 서지정보 조회**에서 전체 명시 DOI·arXiv·OpenReview ID와 자주 언급된 제목 80/160/300개를 조회합니다. Crossref·arXiv·OpenReview 조회와 기존 캐시를 유지하고, 정식 제목의 정확한 결과가 없으면 OpenAlex `search.title` → Semantic Scholar `paper/search/match`로 보완합니다. 대화 본문·프로젝트명은 보내지 않습니다. 성공한 조회는 30일, 일반 오류는 30분 동안 재사용합니다. 429는 Retry-After를 지켜 재시도하며 접근 제한·장기 대기는 제공자별로 저장합니다. 조회 중단 후 완료된 제공자 단계부터 이어갈 수 있습니다. 조회 한도는 아직 완료되지 않은 제목에 적용됩니다. 자세한 저장 구조와 진단 방법은 [서지 연결과 진단](docs/bibliography.md)을 참고하세요. 조회는 서버에서 계속 진행되어 창을 닫아도 중단되지 않습니다. 서버가 종료되면 저장된 캐시를 사용해 다시 실행할 수 있습니다.
- 공식 제목과 기존 표기: 연결된 항목은 서지 API 제목을 대표로 표시합니다. Crossref에서 제목과 부제가 분리된 경우 둘을 합쳐 표시하며, 구형 파서 캐시는 필요한 경우 다시 조회합니다. 저자·연도·출판처·제공자·조회 근거 링크를 상세에 표시하고, **대화에서 발견한 표기**에서 원래 제목·약칭을 확인할 수 있습니다. 원문 위치와 발췌는 수정하지 않습니다. Crossref와 arXiv가 같은 DOI를 제공하면 Crossref 제목을 우선하고 다른 제목도 보존합니다. 같은 제목에 서로 다른 DOI(예: 원판과 재수록판)가 있거나 식별자가 가리키는 논문과 대화의 제목이 크게 다르면 자동 연결하지 않습니다. 논문 페이지·DOI·preprint·PDF 링크와 각각의 제공자 출처는 분리해 보관합니다.
- 자동 병합 기준: 동일 서지 식별자 또는 4개 이상의 의미 있는 단어를 포함한 구체적인 공식 제목의 정규화 후 정확한 일치만 자동 연결합니다. DOI/arXiv 버전은 정규화합니다. 검증된 약칭 사전의 식별자·정식 제목이 모두 맞거나, 약칭이 나온 모든 대화에서 유일한 정식 제목/명시 식별자를 대조할 수 있어야 약칭을 연결합니다. 비슷한 제목·근거 없는 약칭이나 서로 다른 서지 레코드의 충돌은 검토 큐로 보냅니다. 학회·일반 기술·데이터셋·소제목도 자동 연결하지 않습니다. 제목 유사도는 문자열 비교값이며 정답 확률이 아닙니다. 병합 시 동일 메시지·같은 텍스트 위치의 중복 근거는 제거하고, 실제 반복 언급은 유지합니다. 날짜·프로젝트 집계는 합쳐진 논문의 원래 Mention을 기준으로 다시 계산합니다.
- 사람/LLM 검토: 서지 정리의 연결 후보에서 근거 논문을 보고 연결하거나 따로 유지할 수 있습니다. 병합된 상세의 **이 병합 해제**로 원래 후보를 다시 분리할 수 있습니다. 기존 후보의 검토·Zotero 기록은 원본 ID별로 보존하고, 상충하는 Zotero Key는 임의로 선택하지 않습니다. LLM 검토용 JSON에는 미확정 제목·식별자·서지 후보를 내보내며 대화 본문은 제외합니다. LLM API는 연결되어 있지 않고 자동 비용도 발생하지 않습니다. 내보낸 제안은 자동 적용되지 않습니다.
- 대화 기간: 검색창 아래에서 시작일·종료일을 선택하면 **메시지 작성일(한국시간)** 기준으로 필터링합니다. 두 날짜를 모두 포함하며 한쪽 날짜만 지정할 수도 있습니다. 논문 목록·노드 크기·공동 언급 연결·순위·상세 언급·상단 통계가 같은 기간으로 다시 집계됩니다. 오래전에 시작한 대화도 기간 내 작성된 메시지가 있으면 포함합니다. ‘전체 기간’으로 초기화할 수 있고 선택 기간은 주소에 남아 새로고침해도 유지됩니다. 날짜 없는 메시지는 기간 지정 시 제외하며, 수동 입력은 추가한 날짜를 사용합니다. ‘앞뒤 맥락’은 이해를 위해 기간 밖 인접 메시지도 표시할 수 있습니다. 날짜 필터 자체는 재색인 없이 즉시 적용됩니다.
- 대화 분류·프로젝트: 개인 state 폴더의 `projects.json`에 프로젝트 이름과 기본 분류를 연결합니다. 공개 형식 예시는 `examples/demo/projects.example.json`에 있고, 기존 개인 매핑은 Git에 넣지 않습니다. 기본 화면은 전체 대화이며, **수업·과제 제외 (미분류 포함)** / 직접 연구 / 수업·과제 / 미분류 또는 개별 프로젝트를 선택할 수 있습니다. 날짜·분류·프로젝트 필터를 함께 적용하면 그래프·연결·언급·순위·상세·통계를 그 범위로 재집계합니다. 선택 조건은 주소에 저장됩니다.
- 분류의 의미: 논문 자체의 주제나 연구 가치를 판정하지 않고 **언급이 나온 대화의 출처**를 구분합니다. 같은 논문이 수업과 직접 연구에서 모두 언급될 수 있으며, 목록과 상세에 출처별 언급 횟수가 표시됩니다. 이름을 연결하지 않은 프로젝트, 프로젝트 ID가 없는 대화, GPT 대화, 수동 입력은 기본적으로 미분류입니다. 미분류에는 연구 관련 대화도 포함될 수 있으므로 직접 연구나 비연구로 자동 확정하지 않습니다. `프로젝트 정보 없음`은 소속 정보가 없다는 의미입니다.
- 빠뜨린 대화 분류: 상세 언급 카드의 **이 대화 분류**에서 직접 연구·수업·과제·미분류로 지정할 수 있습니다. 같은 대화의 모든 논문 언급에 적용하며, 프로젝트 소속 자체나 원본 Export는 바꾸지 않습니다. `프로젝트 기준` / `기본값`으로 되돌리면 수동 지정이 해제됩니다. 결과는 `.local/conversation-labels.json`에 보관되며 Export 재읽기와 서버 재시작 후에도 유지됩니다.
- 선: **동일 대화에서 공동 언급된 횟수**입니다. 인용·영향·비교 관계를 추론하지 않습니다. 화면 혼잡을 줄이기 위해 공동 언급 수가 많은 선부터 제한해서 표시합니다.
- 논문 클릭: 정확한 발췌와 작성자, 날짜, 앞뒤 메시지를 확인하고 검색 구절을 복사할 수 있습니다. 논문 목록에서는 모든 후보를 페이지 단위로 탐색합니다.
- 원문 열기: export의 대화 ID로 `https://chatgpt.com/c/{id}`를 구성합니다. 해당 계정으로 로그인해야 하며, 삭제된 대화 또는 사이트 변경에 따라 열리지 않을 수 있습니다. 특정 메시지 자동 이동은 구현하지 않았습니다.
- 후보 검토: 직접 확인하거나 제외합니다. 결과는 `.local/reviews.json`에 저장되며 재색인해도 유지됩니다.
- 대화 추가: 텍스트와 선택적으로 원본 링크를 붙여넣습니다. 동일한 텍스트는 해시로 중복 차단합니다. 수동 입력은 작성자를 판별하지 않고 ‘수동 입력’으로 표시하며 내부적으로 user 역할로 집계합니다.
- Export 업데이트: `data/` 안의 기존 export를 새 export로 교체한 뒤 **Export 다시 읽기**를 누르세요. 분할 파일 `conversations-000.json` 등과 `conversations.json` 모두 지원합니다. 동일 대화 ID가 여러 파일에 있으면 update_time이 최신인 것을 택합니다. 재읽기는 전체 스냅샷 재구축이며 메시지 단위 증분 분석은 아직 없습니다.
- Zotero: 상세에서 개인 라이브러리 항목 Key와 PDF 첨부 Key를 각각 등록하면 `zotero://`로 열 수 있습니다. Key는 서로 다릅니다. Zotero 설치와 브라우저의 외부 앱 실행 허용이 필요합니다. 자동 매칭·Local API 동기화·그룹 라이브러리는 미구현입니다.

## 추출 방식과 한계

1. 현재 선택된 `current_node`부터 parent를 따라 대화 경로를 복원합니다. user와 화면에 보이는 assistant의 최종 텍스트만 사용합니다. 도구 출력, 내부 분석, 다른 재생성 분기는 제외합니다. 유효한 current_node가 없는 대화는 임의로 경로를 선택하지 않으며 overview API의 `stats.warnings`에 기록합니다.
2. 본문 식별자·출판사 논문 경로, 명시적 영문 약칭, 연구 맥락의 제목형 구절을 수집합니다. `content_references`에서 본문에 실제로 이름이 나타나는 논문의 인용 URL도 복원합니다. 지원 웹사이트가 다른 논문인 경우 그 제목을 별도로 대조하고, `search_result_groups`에 검색만 된 항목은 언급으로 세지 않습니다. 일반 명사 오탐을 줄이기 위해 단독 이름은 대문자 2개 이상 또는 숫자가 있는 경우만 후보로 삼습니다. 전체 메시지에서 별칭을 다시 탐색하되 대소문자·경계·주변 연구 단서를 확인합니다.
3. 식별자와 구체적인 정식 제목의 유일한 일치를 바탕으로 중복을 합치고, 짧은 별칭은 검증된 사전이나 같은 대화의 명시적 근거로 대조합니다. 서로 다른 식별자의 동일 논문 여부와 약칭 충돌은 완전하게 해결하지 못합니다. 같은 별칭이 여러 논문의 후보일 때도 언급이 모호할 수 있으므로 검토가 필요합니다.
4. Mention은 대화 ID, 메시지 ID, 정확한 텍스트 위치, 내용 해시, 원문 발췌를 보존합니다. 언급 수는 문자열 출현 횟수라 한 메시지의 반복 언급도 포함하며, 사용자/AI 및 서로 다른 메시지/대화 수를 별도로 저장합니다.

**모든 논문을 빠짐없이 찾는 버전이 아닙니다.** 이름이 없는 ‘그 논문’, 링크 없는 일반 제목, 약칭만 있고 연구 단서가 없는 문장은 놓칠 수 있습니다. 모델·데이터셋·연구 제안도 후보에 섞일 수 있습니다. ‘식별자 있음’과 ‘공식 서지정보 연결됨’은 구별하며, 서지정보가 확인되어도 원래 대화의 인용 의도까지 검증하는 것은 아닙니다. Assistant가 잘못 생성한 링크는 조회 오류나 검토 대상으로 남을 수 있습니다. 전처리 단계에서 이미 묶인 로컬 별칭 사전 자체의 분리/편집, PDF 전문 분석, LLM 자동 판별은 아직 지원하지 않습니다.

수동 입력과 나중의 export 사이 자동 중복 병합은 없습니다. 붙여넣기와 export가 겹치면 별도 출처로 계산됩니다. 텍스트는 안전하게 일반 텍스트로 렌더링하며 HTML/Markdown·수식·첨부 이미지·인터랙티브 Figure는 재현하지 않습니다. 긴 메시지의 맥락은 24,000자까지 표시합니다.

## 데이터와 실행

원본 대화 처리는 로컬에서 수행하며 서버는 `127.0.0.1`에만 바인딩합니다. 외부 스크립트·폰트·분석 도구 요청은 없습니다. 선택적인 서지 조회에서는 서버가 `api.crossref.org`, `export.arxiv.org`, `api2.openreview.net`, `api.openalex.org`, `api.semanticscholar.org`에 논문 제목·식별자를 보냅니다. 원문 링크와 Zotero 버튼은 클릭할 때 외부 페이지/앱을 엽니다. 서버는 `data/` 자체를 웹으로 노출하지 않습니다. 인증은 없으므로 포트 포워딩하거나 공유 호스팅에 올리지 마세요.

`data/`와 `.local/`은 `.gitignore`에서 제외합니다. `sources.json`, `reviews.json`, `projects.json`, `conversation-labels.json`, `bibliography-decisions.json`에는 사용자의 입력·분류·연결 결정이 있어 보관해야 합니다. `index.json`은 원본 추출 캐시, `bibliography.json`은 공식 조회 결과·조회 캐시, `bibliography-job.json`은 진행 상태입니다. 원본 Export는 수정하지 않습니다. 프로젝트 이름이나 기본 분류를 파일에서 바꾼 경우 서버를 재시작하면 적용됩니다. Windows 동기화 폴더의 일시적 파일 잠금에는 재시도합니다. 장시간 파일 교체가 막히면 `파일명.v-시간-….json` 스냅샷에 기록하고 앱은 최신 스냅샷을 자동으로 읽습니다. 최근 3개를 유지하므로 기본 JSON 파일과 이 스냅샷들을 함께 보관하세요. 기존 파일을 먼저 지우거나 덮어쓰기 중간 상태로 노출하지 않습니다.

```powershell
node server.mjs --index  # 서버 없이 색인 재구축
npm.cmd test            # 분기 복원, 식별자 정규화, 중복/공동 언급 집계 검증
npm.cmd run check       # JavaScript 구문 검사
```

`$env:PORT=4318; node server.mjs`로 포트를 바꿀 수 있습니다. 서버 종료는 해당 터미널에서 Ctrl+C입니다.
