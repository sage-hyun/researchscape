BIBLIOGRAPHIC IDENTITY

공식 제목 연결 · 중복 정리

대화에서 발견한 표기는 보존합니다. 식별자·구체적인 정식 제목·검증된 약칭 근거가 유일할 때 자동 연결하고, 모호하거나 충돌하는 후보는 아래에서 검토합니다.

DOI·arXiv·OpenReview 식별자를 조회하고, 정식 제목은 Crossref → OpenAlex → Semantic Scholar 순으로 보완합니다. 검증된 약칭은 사전의 식별자와 대조합니다. 대화 원문·프로젝트명은 보내지 않으며 성공한 조회 결과는 캐시합니다. LLM은 자동 호출하지 않습니다.

서지 검토

아직 연결되지 않은 후보 전체를 파일 하나로 내려받아 LLM에 맡기고, 결과 JSON도 한 번에 가져옵니다. 파일에는 대화 본문·프로젝트명·Zotero Key를 넣지 않으며 LLM은 자동 호출하지 않습니다.

전체 LLM 검토 JSON 다운로드

통합 검토 목록 · 검토 결과 미리보기

공식 조회 후보와 LLM 결과를 한곳에서 검토합니다. 체크한 항목만 적용하며, 공식 레코드가 있어도 약칭과의 연결은 직접 확인해주세요.

아직 연결·후보 제외·별도 유지 결정을 저장하지 않은 항목입니다.

FIGURE LIBRARY

Figure 추출 · 갤러리

확보한 로컬 PDF에서 Figure를 추출합니다. 대표 이미지는 기본 Figure 1이며 논문 상세에서 다른 Figure 또는 직접 Crop한 이미지로 바꿀 수 있습니다.

Zotero 전체 추출은 대화에 연결되지 않은 PDF까지 순차 처리합니다. 완료된 결과는 재사용하며, 대표 이미지·수동 Crop·원본 PDF·Zotero 주석을 보존합니다. PDF 다운로드나 외부 AI 호출은 하지 않습니다. 서버가 실행 중이면 창을 닫아도 작업이 계속됩니다.
ZOTERO CONNECTION

프로젝트 Collection 동기화

ChatGPT 프로젝트를 Zotero Collection으로 연결합니다. 기존 분류는 유지하며, 미리보기 후 승인한 항목만 추가합니다.

1. Zotero 연결

연결 확인 전

연결 설정 방법
  1. Researchscape 서버가 실행 중인 PC에서 Zotero 10을 실행합니다.
  2. Zotero 설정 → 고급에서 Allow other applications on this computer to communicate with Zotero를 켭니다.
  3. 연결 확인을 누릅니다. 읽기 연결이 되면 미리보기를 사용할 수 있습니다.
  4. 실제로 저장하기 전에 쓰기 권한 요청을 누르고 Zotero 창에서 승인합니다.

읽기 허용 설정과 쓰기 승인은 별개입니다. 별도 테스트 프로필의 승인은 개인 프로필에 적용되지 않으며, 서버 재시작 후에는 쓰기를 다시 승인해야 합니다.
