LLM 검토용 JSON 받기

전체 DOI·arXiv·OpenReview 식별자와 선택한 수의 제목을 해당 공식 API에 조회합니다. 대화 원문·프로젝트명은 보내지 않으며 성공한 조회 결과는 캐시합니다. LLM은 자동 호출하지 않습니다.
