공식 제목 연결 · 중복 정리

대화에서 발견한 표기는 보존합니다. 식별자·구체적인 정식 제목·검증된 약칭 근거가 유일할 때 자동 연결하고, 모호하거나 충돌하는 후보는 아래에서 검토합니다.

전체 진단 JSON

DOI·arXiv·OpenReview 식별자를 조회하고, 정식 제목은 Crossref → OpenAlex → Semantic Scholar 순으로 보완합니다. 검증된 약칭은 사전의 식별자와 대조합니다. 대화 원문·프로젝트명은 보내지 않으며 성공한 조회 결과는 캐시합니다. LLM은 자동 호출하지 않습니다.

LLM 검토용 compact JSON

긴 출처·조회 URL과 대화 본문을 제외합니다. 연결 후보가 있는 항목과 없는 항목은 중복 없이 나눕니다.

이 묶음 JSON 받기

LLM 검토 결과 가져오기 · 미리보기 후 최종 승인

입력 JSON 스키마 · schemaVersion: 1, decisions 배열을 사용합니다. LLM 호출은 자동 실행하지 않습니다. needsManualReview 항목과 Work·Version 제안은 일괄 적용하지 않습니다.
YOUR PAPER LIBRARY

PDF 확보 · Figure 갤러리

Zotero의 PDF를 먼저 연결하고, 없는 논문은 공개 PDF를 찾아봅니다. 기본 대표 이미지는 Figure 1이며, 논문 상세에서 다른 Figure나 직접 고른 영역으로 바꿀 수 있습니다.

원본 PDF·Zotero DB는 변경하지 않습니다. 추출은 내 컴퓨터에서 순차 실행하며 PDF를 외부 AI에 보내지 않습니다. 로그인·사람 확인이 필요하면 브라우저에서 직접 다운로드한 PDF를 논문 상세에 연결해주세요.

전체 추출은 10편 시험 제한을 해제하고, 대화에 연결되지 않은 Zotero PDF까지 한 편씩 처리합니다. 기존 결과와 직접 고른 대표 이미지는 유지하며, PDF를 추가 다운로드하지 않습니다. 브라우저를 닫아도 이 PC의 Researchscape 서버가 실행 중이면 계속됩니다.

Zotero 10 · 프로젝트 Collection 동기화

기존 Zotero 서지 항목에 Collection만 추가합니다. 항목·컬렉션 삭제와 논문 자동 생성은 하지 않습니다. 처음에는 1~3편으로 확인하세요.
